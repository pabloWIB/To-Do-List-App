# JS To-Do App

A simple, interactive to-do list application built with vanilla JavaScript. Features task management, local storage persistence, and a clean user interface for organizing daily tasks.

## Tech Stack

- **HTML5** - Semantic structure and form elements
- **CSS3** - Modern styling and responsive design
- **Vanilla JavaScript** - Task management and DOM manipulation

## File Structure

```
JS-To-Do/
├── index.html          # Main application page
├── style.css           # Styling and layout
├── script.js           # Task functionality and logic
└── README.md           # Project documentation
```

## Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/pabloWIB/JS-To-Do.git
   ```

2. **Open index.html** in your browser

3. **Start managing your tasks** - add, complete, and organize your to-dos

## Features

- Add new tasks with simple input
- Mark tasks as complete or incomplete
- Delete tasks when no longer needed
- Clean, intuitive user interface
- Responsive design for mobile and desktop
- Task persistence between browser sessions

## Customization

**Update functionality:**
- Modify task management logic in `script.js`
- Add categories or priority levels
- Implement task filtering and sorting

**Style changes:**
- Customize colors and typography in `style.css`
- Adjust layout and spacing
- Add animations and transitions

## Deployment Options

Deploy your to-do app:

- **GitHub Pages** - Enable in repository settings
- **Netlify** - Drag and drop deployment
- **Vercel** - Connect GitHub repository
- **Surge.sh** - Command line deployment
